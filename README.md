# 抢场地脚本

## 第三方包使用说明

本项目采用 python 3.12，基于前辈的脚本进行改造。项目采用 uv 进行包管理。

- selenium: 实现浏览器自动化操作
- loguru: 进行日志记录

## 创建并激活虚拟环境

首先通过 uv 创建虚拟环境：

```cmd
uv sync
```

然后通过 uv 提供的脚本激活虚拟环境

```cmd
.venv\Scripts\activate.bat
```

## 使用说明

修改`main.py`开头的全局参数来设置用户名、密码、支付密码、校区、要预约的运动类型、要预约的时间段（可以多个）、要预约的日期（硬编码或默认第二天）

使用 python 命令运行 main.py 文件即可。

```
python main.py
```
